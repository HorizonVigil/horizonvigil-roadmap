# Admin Console

The Admin Console is a separate privileged product surface delivered before V1 market entry.

## Order

1. Separate authentication, MFA and staff roles
2. Tenant/member lifecycle and domain verification
3. Plans, subscriptions, entitlements, usage and billing
4. Connector/job/queue/platform health
5. Support cases and redacted diagnostics
6. Feature flags, incidents and maintenance
7. Privileged approvals, just-in-time access and break-glass
8. Immutable staff audit, reports and access recertification

Customer impersonation or support access requires a reason, time limit, visible audit record and safeguards against mutation or cross-tenant access.
